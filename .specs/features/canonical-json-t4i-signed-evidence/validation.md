## Follow-up compatibility correction (issue #58)

The original T4i implementation retained `localeCompare` in the V1 branch of
the shared identity comparator. That changed historical V1 bytes for mixed-case
identifiers even though the pinned fixture used only values that did not
discriminate the collations. The correction in this branch restores the
historical JavaScript UTF-16 code-unit ordering explicitly for V1 and keeps the
same locale-independent ordering for V2.
