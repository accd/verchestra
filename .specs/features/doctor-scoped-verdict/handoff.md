# Scope

Exit condition X5: a user of the published package must be able to reach a
`doctor` `PASS`. Six deep-doctor checks observe subsystems that no product
command provisions. They are `cedar-policy`, `connector`, `driver`, `probe`,
`sandbox` and `sqlite-durable-state`. The plan
(`.specs/features/doctor-scoped-verdict/plan.md`) scopes the verdict instead
of documenting fixture files for users to create. The checks are in
`checks.md`, and AD-088 in `.specs/STATE.md` records the three doors.
